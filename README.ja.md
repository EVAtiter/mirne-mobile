# mirne mobile

公式ファームウェアの nasne を LAN から使う macOS・iOS・iPadOS アプリです。番組表を見る、録画予約を管理する、
録画した番組やいま放送中の番組を Mac・iPhone・iPad で見る、ができます。iPhone・iPad 版も Mac 版と同じ機能です。

## 非公式のアプリです

**mirne mobile は、独立した非公式のアプリです。** ソニー・インタラクティブエンタテインメント、バッファロー、
DTLA（Digital Transmission Licensing Administrator）、そのほかの標準化団体やメーカーとは関係がなく、
承認や認定も受けていません。「nasne」「DTCP-IP」は、それぞれの権利者の商標です。

このソースのライセンスは、DTCP-IP などの技術に関わる特許や商標の使用を許諾するものではなく、
それらを侵害しないことも保証しません。

## 主な機能

- **番組表**：nasne が持つ地上デジタルの番組表を 8 日分、局のロゴと一緒に表示します。予約済みの番組には印が付きます。番組を押すと詳細を出し、そこから録画予約できます
- **予約**：予約の一覧・作成（局と時刻を指定、または番組表の番組から）・画質の変更・削除。作る前に重なる予約を確かめます。行の頭に局のロゴを出し、選んだ予約は情報のカードで表示します
- **録画**：録画の一覧を検索・並べ替え・同じ番組名でまとめて表示します。行の頭に局のロゴを出し、視聴の状態（未再生・途中まで・見終わった）を印と行の淡い色で表示します。選んだ録画は、情報と再生・保護・削除のボタンをまとめたカードで表示します。前回の一覧をすぐに出し、約 1 秒で nasne の最新に合わせます
  - 途中で止めた録画は続きから再生できます。続きの位置は nasne にも保存し、ほかの Mac・iPhone・iPad や torne と共有します（設定で切れます）
  - 録画の保護の切り替えと削除ができます
- **再生**：DR・3倍・モバイルの録画を再生します。録画中の録画も再生できます
  - 字幕・二重音声（主・副・主＋副）・音声の切り替え
  - シーク・10 秒戻る / 進む・チャプターへ前後に飛ぶ（nasne が付けたチャプター。位置のつまみに印）・再生中の画質の切り替え・再生速度（1・1.25・1.5・2 倍。音の高さは変わりません）
  - 操作部は、横長の画面では再生の操作を中央に置いた 1 段、縦長の画面では 2 段です
  - 全画面・常に最前面・標準の大きさに戻す
- **ライブ視聴**：放送中の番組を見られます。局は操作部のメニュー・↑↓・数字キーで切り替えます。nasne が録画している間は録画中の局を映します
- **情報**：nasne の本体・HDD の空き・録画中の番組・お知らせ・録画できなかった予約を表示します
- **そのほか**：nasne のアドレスが変わったときやネットワークを切り替えたときは、自動で探し直します。窓の位置と大きさを覚えます。再生中はディスプレイがスリープせず、Mac がスリープするときは再生を止めます
- **iPhone・iPad**：番組表・予約・録画・情報・再生・ライブ視聴は Mac 版と同じです。録画と予約は行をタップして選ぶとカードが出て、録画は行のダブルタップで再生します。再生の画面は全画面で、タップで操作部を出し、画面の左半分・右半分のダブルタップで 10 秒戻る / 進む（録画）ができます。アプリが裏へ回ると再生を止め、戻ると止めた位置から続けます
  - iPhone の縦向きのような狭い画面では、画面を下のタブで切り替え、選んだ録画・予約のカードは下からのシートで出します。帯のボタンは絵にし、番組表は 2 局ずつ並べます。機能は減らしていません

## インストール

### Mac

[Releases](https://github.com/EVAtiter/mirne-mobile/releases/latest) から `mirne-mobile-<バージョン>.zip` をダウンロードして展開し、
`mirne mobile.app` を「アプリケーション」フォルダーへ移します。アプリは Apple の公証を受けています。

[Homebrew](https://brew.sh/) でもインストールできます。

```bash
brew install --cask EVAtiter/tap/mirne-mobile
```

「untrusted tap」と表示されたら、先に次のコマンドでこの cask を信頼してから、もう一度インストールしてください。

```bash
brew trust --cask evatiter/tap/mirne-mobile
```

### iPhone・iPad

iPhone・iPad 版は App Store にはありません。[Releases](https://github.com/EVAtiter/mirne-mobile/releases/latest) から
`mirne-mobile-<バージョン>.ipa` をダウンロードしてください。IPA は署名していないので、LiveContainer・AltStore・SideStore などの
サイドロードの道具で、自分で署名して入れます。

同じ Release に、iPhone・iPad 版に同梱している FFmpeg のソース（`ffmpeg-<バージョン>.tar.xz`）も置いています。[NOTICE](NOTICE) を参照してください。

## 使い方

1. **nasne を登録する**：初めて起動すると、同じネットワークの nasne を探します。見つからないときは、
   ネットワークを順に調べるか、nasne の IP アドレス（またはデバイス記述の URL）を入れて登録します。
   この Mac が nasne に許可されていないときは、nasne HOME のメディアサーバーの設定で許可します
2. **資格情報を取り込む**（録画とライブを見るときだけ）：「設定」の「資格情報（DTCP-IP）」で、
   自分の機器から得た証明書と秘密鍵の 2 つのファイルを選びます（`credentials.env` からも取り込めます）。
   番組表・予約・録画一覧は、資格情報が無くても使えます
3. **見る**：ツールバーの中央で「番組表」「予約」「録画」「情報」を切り替えます。録画は一覧で選ぶと出るカードの
   再生のボタンで再生します（行のダブルクリック・Return でも）。ライブはツールバーの「ライブ」か、番組表の局名の横のボタンで始めます

視聴ウィンドウの主なキー操作：

| キー | 操作 |
| --- | --- |
| スペース | 一時停止・再開 |
| ← / → | 10 秒戻る / 進む（録画） |
| Shift + ← / → | 前 / 次のチャプター（録画） |
| ↑ / ↓・数字キー | 局の切り替え（ライブ） |
| ⌘↑ / ⌘↓ | 音量 |
| M | ミュート |
| A | 音声の切り替え |
| C | 字幕の表示 |
| Q | 画質の切り替え |
| S | 再生速度（録画） |
| F | 全画面 |
| Esc | 全画面を抜ける |
| T | 常に最前面 |
| ⌘0 | 標準の大きさに戻す |

主ウインドウでは、⌘1〜⌘4 で画面を切り替え、⌘R で更新、⌘N で新しい予約を作ります。

iPhone・iPad では：

- nasne を登録するとき、先にローカルネットワークの使用の許可を聞いてから、ネットワークを順に調べます（iPhone・iPad 版は SSDP を使いません）。
  許可してください。許可しなかったときは、設定の「プライバシーとセキュリティ」→「ローカルネットワーク」で mirne mobile を許可します
- 資格情報のファイルは「ファイル」アプリから選びます
- 狭い画面では、「番組表」「予約」「録画」「情報」を画面の下のタブで切り替えます
- 再生の画面は、タップで操作部を出し入れし、左上の × で閉じます。音量は本体の音量ボタンで変えます。ハードウェアキーボードでは、
  上のキー操作が F・Esc・T・⌘0 を除いて使えます
- ハードウェアキーボードでは、主画面で ⌘1〜⌘4・⌘R・⌘N・⌘F（録画の検索）・⌘L（ライブ）・⌘,（設定）が使えます

## DTCP-IP の資格情報について

録画とライブの再生には、DTCP-IP の機器の資格情報ペア（DTLA 証明書と機器秘密鍵）が要ります。
**mirne mobile は資格情報を含みません。** 自分の機器から得た自分のペアを設定から取り込んだときだけ、
再生できるようになります。取り込んだペアはその Mac・iPhone・iPad のキーチェーンにだけ保存し（同期しない）、
セッション鍵はメモリの中だけに置きます。復号したコンテンツをディスクに書くことはありません。

ペアの入手と使用が、使用許諾と法令に照らして許されるかは、利用する人が判断してください。
このリポジトリは、ペアの入手先や取り出し方を案内しません。

## 動作環境

- Apple Silicon の Mac と macOS 15 以降、iOS 18 以降の iPhone、または iPadOS 18 以降の iPad
- 同じ LAN にある、公式ファームウェアの nasne

iPhone・iPad 版は、iOS 27 の iPhone 17 Pro と iPadOS 27 の iPad Air で動作を確かめています。

バッファロー製の nasne（システムソフトウェア 4.50）で動作を確かめています。ソニー・インタラクティブエンタテインメント製の
nasne については、torne mobile HomeBrew edition の実測（システムソフトウェア 2.60）をもとに作っています。

## ビルド

Xcode と [XcodeGen](https://github.com/yonaskolb/XcodeGen) が要ります。

```bash
./build.sh          # Debug でビルド（Release は ./build.sh release）
./build.sh test     # 単体試験を流す
```

アプリは `build/symroot/<構成>/mirne mobile.app` にできます。既定はアドホック署名です。
自分の証明書で署名するには、`Config/Local.xcconfig.example` を `Config/Local.xcconfig` に複製して書き換えます。

iPhone・iPad 版はスキーム `mirne-mobile-iOS` です。初めてビルドするとき、`scripts/build-ffmpeg-ios.sh` が ffmpeg.org から FFmpeg を取り、
SHA-256 を照合して、MPEG-2 の映像の復号器を動的なフレームワークに組みます（数分かかります）。
`scripts/build-ipa.sh` で、署名なしの IPA が `build/ipa` にできます。
