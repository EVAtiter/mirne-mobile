# mirne mobile

公式ファームウェアの nasne を LAN から使う macOS アプリです。番組表を見る、録画予約を管理する、
録画した番組やいま放送中の番組を Mac で見る、ができます。iOS / iPadOS 版も予定しています。

## 非公式のアプリです

**mirne mobile は、独立した非公式のアプリです。** ソニー・インタラクティブエンタテインメント、バッファロー、
DTLA（Digital Transmission Licensing Administrator）、そのほかの標準化団体やメーカーとは関係がなく、
承認や認定も受けていません。「nasne」「DTCP-IP」は、それぞれの権利者の商標です。

このソースのライセンスは、DTCP-IP などの技術に関わる特許や商標の使用を許諾するものではなく、
それらを侵害しないことも保証しません。

## 主な機能

- **番組表**：nasne が持つ地上デジタルの番組表を 8 日分、局のロゴと一緒に表示します。予約済みの番組には印が付きます。番組を押すと詳細を出し、そこから録画予約できます
- **予約**：予約の一覧・作成（局と時刻を指定、または番組表の番組から）・画質の変更・削除。作る前に重なる予約を確かめます
- **録画**：録画の一覧を検索・並べ替え・同じ番組名でまとめて表示します。前回の一覧をすぐに出し、nasne から取り直したものに差し替えます。視聴の状態（未再生・途中まで・見終わった）を印で表示し、途中で止めた録画は続きから再生できます。録画の削除もできます
- **再生**：DR・3倍・モバイルの録画を再生します。録画中の録画も再生できます
  - 字幕・二重音声（主・副・主＋副）・音声の切り替え
  - シーク・10 秒戻る / 進む・再生中の画質の切り替え・再生速度（1・1.25・1.5・2 倍。音の高さは変わりません）
  - 全画面・常に最前面・標準の大きさに戻す
- **ライブ視聴**：放送中の番組を見られます。局は操作部のメニュー・↑↓・数字キーで切り替えます
- **情報**：nasne の本体・HDD の空き・録画中の番組・お知らせ・録画できなかった予約を表示します
- **そのほか**：nasne のアドレスが変わったときやネットワークを切り替えたときは、自動で探し直します。窓の位置と大きさを覚えます。再生中はディスプレイがスリープせず、Mac がスリープするときは再生を止めます

## インストール

[Releases](https://github.com/EVAtiter/mirne-mobile/releases/latest) から `mirne-mobile-<バージョン>.zip` をダウンロードして展開し、
`mirne mobile.app` を「アプリケーション」フォルダーへ移します。アプリは Apple の公証を受けています。

[Homebrew](https://brew.sh/) でもインストールできます。

```bash
brew install --cask EVAtiter/tap/mirne-mobile
```

「untrusted tap」と表示されたら、先に次のコマンドでこの cask を信頼してから、もう一度インストールしてください。

```bash
brew trust --cask evatiter/tap/mirne-mobile
```

## 使い方

1. **nasne を登録する**：初めて起動すると、同じネットワークの nasne を探します。見つからないときは、
   ネットワークを順に調べるか、nasne の IP アドレス（またはデバイス記述の URL）を入れて登録します。
   この Mac が nasne に許可されていないときは、nasne HOME のメディアサーバーの設定で許可します
2. **資格情報を取り込む**（録画とライブを見るときだけ）：「設定」の「資格情報（DTCP-IP）」で、
   自分の機器から得た証明書と秘密鍵の 2 つのファイルを選びます（`credentials.env` からも取り込めます）。
   番組表・予約・録画一覧は、資格情報が無くても使えます
3. **見る**：ツールバーの中央で「番組表」「予約」「録画」「情報」を切り替えます。録画は一覧で選んで
   「再生」（行のダブルクリック・Return でも）、ライブはツールバーの「ライブ」か、番組表の局名の横のボタンで始めます

視聴ウィンドウの主なキー操作：

| キー | 操作 |
| --- | --- |
| スペース | 一時停止・再開 |
| ← / → | 10 秒戻る / 進む（録画） |
| ↑ / ↓・数字キー | 局の切り替え（ライブ） |
| ⌘↑ / ⌘↓ | 音量 |
| M | ミュート |
| A | 音声の切り替え |
| C | 字幕の表示 |
| Q | 画質の切り替え |
| S | 再生速度（録画） |
| F | 全画面 |
| T | 常に最前面 |
| ⌘0 | 標準の大きさに戻す |

主ウインドウでは、⌘1〜⌘4 で画面を切り替え、⌘R で更新、⌘N で新しい予約を作ります。

## DTCP-IP の資格情報について

録画とライブの再生には、DTCP-IP の機器の資格情報ペア（DTLA 証明書と機器秘密鍵）が要ります。
**mirne mobile は資格情報を含みません。** 自分の機器から得た自分のペアを設定から取り込んだときだけ、
再生できるようになります。取り込んだペアは macOS のキーチェーンにだけ保存し（この Mac だけ・同期しない）、
セッション鍵はメモリの中だけに置きます。復号したコンテンツをディスクに書くことはありません。

ペアの入手と使用が、使用許諾と法令に照らして許されるかは、利用する人が判断してください。
このリポジトリは、ペアの入手先や取り出し方を案内しません。

## 動作環境

- Apple Silicon の Mac
- macOS 15 以降
- 同じ LAN にある、公式ファームウェアの nasne

バッファロー製の nasne（システムソフトウェア 4.50）で動作を確かめています。ソニー・インタラクティブエンタテインメント製の
nasne については、torne mobile HomeBrew edition の実測（システムソフトウェア 2.60）をもとに作っています。

## ビルド

Xcode と [XcodeGen](https://github.com/yonaskolb/XcodeGen) が要ります。

```bash
./build.sh          # Debug でビルド（Release は ./build.sh release）
./build.sh test     # 単体試験を流す
```

アプリは `build/symroot/<構成>/mirne mobile.app` にできます。既定はアドホック署名です。
自分の証明書で署名するには、`Config/Local.xcconfig.example` を `Config/Local.xcconfig` に複製して書き換えます。
